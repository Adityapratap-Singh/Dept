# GURUVERSE 2026 🎓

Premium static Teachers' Day website built with **HTML + CSS + vanilla JavaScript**.

## Run
Open `index.html` in a browser. No backend or build step is required.

## Customize the 10 teachers
Open `script.js` and edit the `teachers` array at the top.

Each teacher has:
- name
- role
- subject
- department
- academic journey
- message
- achievement
- teaching philosophy
- student memory

The two HODs are the first two objects; the remaining eight are displayed as teachers.

## Included features
- Responsive premium landing page
- 2 dedicated HOD profiles
- 8 teacher profiles
- Full-screen profile modal
- Scroll reveal animations, ambient effects and progress bar
- Mobile navigation

## Images
Faculty portraits are loaded from the local `image/` folder. The filenames are mapped in the `teachers` array in `script.js`; profiles without a matching file continue to use the typographic initials fallback.

## Important
This version is frontend-only. LocalStorage is used for tributes, quiz scores, awards and the time capsule. For real multi-student submissions, connect these actions to a backend/database such as Supabase.
